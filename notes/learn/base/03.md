> 支持 adaptive thinking 的新模型

adaptive thinking 和  thinking 有什么区别？

---

我先把 thinking 文档里讲配置模式的那张表读一遍，再回答。

这里没有"thinking 对 adaptive thinking"这种并列关系。thinking 是总称，adaptive 和 extended 是两种控制方式。

## 区别：谁决定想多少

| | 手动模式（extended thinking） | adaptive thinking |
|---|---|---|
| API 写法 | `thinking: {type: "enabled", budget_tokens: 8000}` | `thinking: {type: "adaptive"}` |
| 谁决定想多少 | 你，用 `budget_tokens` 划一个预算 | 模型，根据问题难度自己判断 |
| 简单问题 | 也会想（预算内） | 可以不想 |
| 怎么调深浅 | 改 `budget_tokens` | 用 `effort` 参数 |

Anthropic 对 adaptive 的描述是：*"lets Claude determine when and how deeply to think based on the request."* 在支持 effort 的地方，*"effort is the recommended way to control thinking depth"*。

## 为什么会有 adaptive

手动预算有两个问题。你得提前猜这个问题需要多少思考，猜大了浪费钱，猜小了质量差。而且一次对话里每个问题难度不同，一个固定预算不可能都合适。所以官方把"想多少"的决定权交给了模型。

## 模型支持情况（来自 thinking 文档里的模型对照表）

- **Claude 5 系列**（Opus 5.5、Sonnet 5.5、Haiku 5.5、Fable、Mythos 等）：不传 `thinking` 字段就是 adaptive。传 `enabled` 加 `budget_tokens` 会返回 **400 错误**。Opus 5.5 和 Fable 5.1 连 `disabled` 都是 400，所以这两个模型的思考关不掉，只能用 effort 调低。
- **Opus 4.6、Sonnet 4.6**：默认关闭，可以传 adaptive 打开。手动预算标为 deprecated。
- **Opus 4.5、Sonnet 4.5、Haiku 4.5**：只支持手动预算，传 adaptive 会 400。

## 对你代码的影响

回到我上一条里提到的 SDK 逻辑，`@ai-sdk/anthropic` 的 `resolveAnthropicReasoningConfig` 就是按这个差别分叉的：

- 模型支持 adaptive：翻译成 `{type: "adaptive"}` 加 `effort`
- 模型只支持手动：翻译成 `{type: "enabled", budgetTokens}`，预算按 `maxOutputTokens` 的百分比算

这也解释了为什么我之前提醒"旧模型上 `high` 加 16000 的 `maxOutputTokens` 会让 thinking 占掉约 9600"。这个风险只存在于手动模式。在 adaptive 模型上，模型自己决定想多少，但 thinking 仍然计入 `max_tokens`，所以上限太低还是会挤掉正文。

你项目的 thread-chat 路径（`chatAnswerGenerationOptions`）直接传了 `thinking: {type: "adaptive", display: "summarized"}`，只适用于支持 adaptive 的模型。从 `token-router.ts` 看，Claude 模型都挂了 `adaptiveGenerationCapabilities`，所以这条路径目前对得上。

## 一个相关的坑

文档里说 adaptive 和手动模式在**工具循环**里也不一样：手动模式下，强制工具调用（`tool_choice` 为 `any` 或指定某个工具）会报错，只允许 `auto` 或 `none`。文档同一段说 adaptive 不受这个限制，但那句话我只读到了开头，没看到完整限制条件。你代码的 `prepareStep` 在第 0 步用了强制 `toolChoice: { type: "tool", ... }`。这在 adaptive 的 Claude 模型上应该没问题，但如果以后有人给旧版 Claude（4.5 系）配了 `reasoning`，就可能触发这个报错。我没有实际测过。
