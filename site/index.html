引用文件@

一个 harness 该有的，
都在。

工具

读、写、搜索、执行命令。任意 MCP server 接上就能用。

会话

每一步都写进事件日志。中断了、进程挂了，接着跑。

沙箱

在本机目录上跑，或者在 Docker 里的仓库副本上跑。

权限

每次工具调用都过一遍规则：放行、拒绝，或者先问你。

上下文

对话变长时自动压缩，长任务不断片。

Skills 与记忆

SKILL.md 按需加载，笔记跨会话留着。

子 agent

把一块活儿交给子 agent，结果再回到主线。

Gateway

HTTP 和 SSE 接入，签名 webhook 连到聊天软件。

观测与评测

事件导出成 OpenTelemetry，同一份事件拿来跑 eval。

每一层，都能换。

十三个小包，只靠带版本号的事件相连。换模型、换存储、换沙箱，其余不动。

01@hue/core

类型、事件和循环

ModelPort · Tool · SandboxPort …
02@hue/ai

模型适配

model('anthropic:claude-sonnet-5-5')
03@hue/tools

工具

tools: codingTools()
04@hue/store

事件日志

store: sqliteStore('hue.db')
05@hue/context

上下文压缩

context: foldToolResults()
06@hue/skills

按需加载 SKILL.md

skills: fromDir('./skills')
07@hue/memory

跨会话笔记

memory: file('./notes')
08@hue/policy

放行、拒绝或先问

policy: presets.coding()
09@hue/sandbox

在哪里执行

sandbox: await local({ root: '.' })
10@hue/runtime

把各层装成 agent

createAgent({ model, tools, store, … })
11@hue/gateway

HTTP、SSE 和 webhook

createGateway({ agent })
12@hue/telemetry

导出 OpenTelemetry

otlpHttp({ url })
13@hue/eval

跑任务、打分

codingTasks()

也能写进
你的代码。

挑几层，拼一份配方。hue 命令本身就是这样拼出来的。

import { createAgent } from '@hue/runtime' import { model } from '@hue/ai' import { codingTools } from '@hue/tools' import { sqliteStore } from '@hue/store' import { local } from '@hue/sandbox' import { presets } from '@hue/policy' const agent = createAgent({ model: model('anthropic:claude-sonnet-5-5'), tools: codingTools(), store: sqliteStore('hue.db'), sandbox: await local({ root: '.' }), policy: presets.coding(), }) for await (const e of agent.run('修好失败的测试')) render(e)
